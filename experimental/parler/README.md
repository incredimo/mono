# Parler TTS Experiment

This directory contains an experimental script for Text-to-Speech (TTS) using the `parler-tts` library.
It is not directly related to the core functionality of the `mono` project (Android device logging and data extraction).

## Dependencies

This script requires Python and the following libraries:
- torch
- parler-tts
- transformers
- soundfile

These are not part of the main Rust project's dependencies.
